# app/Views/ — View layer (HTML)

**Safe to customize** — layouts, markup, CSS classes.

| Folder | Contents |
|--------|----------|
| `layouts/` | `header.php`, `footer.php`, `admin-nav.php` |
| `pages/` | Page bodies (about, contact, faq, …) |
| `partials/` | Reusable chunks (news-card, comment-item) |
| `View.php` | Template renderer class |

Loaded by controllers — **not** reachable by URL.

Guide: [docs/STRUCTURE.md](../../docs/STRUCTURE.md)
